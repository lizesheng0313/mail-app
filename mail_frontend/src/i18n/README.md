# 界面语言

网站及共用此界面的桌面客户端支持简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语、葡萄牙语。原生语言名称、短名称、Open Graph 地区和 AI 写信语言统一定义在 `locales.ts`。

- 首次访问按照浏览器语言优先级选择已支持的语言；没有匹配时显示英文。已有手动选择优先，并保存到 `app.locale`。
- 中文以外的语言按需加载，新增语言包独立分块；同时加载英文作为缺失词条的备用语言。繁体中文继续以简体中文备用。
- 六个新增语言包覆盖 `en.ts` 的全部界面词条，保留 `{count}` 等参数、示例邮箱、协议名和金额币种。不要通过展开英文对象假装完成翻译。
- 六个语言包初稿经机器翻译生成，支付范围、币种、充值单位、订单到账等关键文案已逐项调整；未做母语专业审校。
- 帮助中心正文及后台返回的 API 技术文档目前只有中文和英文版本；新增语言使用现有英文内容。用户创建的邮件、商品、公告等业务内容不会被界面切换自动翻译。后台原有未国际化页面也不属于新增语言包的覆盖范围。
- 翻译结果是项目内静态文件，应用运行时不调用外部翻译服务。

新增或修改词条后运行 `pnpm exec vitest run src/i18n src/components/LanguageSwitcher src/api/helpCenter.test.ts src/utils/timeUtils.test.ts src/seo/multilingual.test.ts`，检查键完整性、参数、实际 vue-i18n 编译、浏览器识别、刷新保持和切换竞争。再运行 `pnpm run build` 检查分块及首屏预算。
