# 网页加载优化（2026-10-20）

## 调整

- 移除把所有依赖合并到公共 vendor 的构建配置，保留路由拆包。
- 写信编辑器、Excel、充值二维码和其他语言包按使用时机加载；登录客服按需加载。
- 登录校验由路由守卫统一处理，避免启动时重复查询用户信息。
- 工作台只获取当前邮箱类型的数据；邮箱列表和邮件并行获取。
- 分享页在邮箱信息返回后显示地址，独立加载邮件，并忽略过期的列表响应。
- 手机端隐藏的小程序图片延迟加载，缩小 favicon。
- Nginx 对文件名带构建哈希的资源设置一年 immutable 缓存，HTML 和无版本公共资源继续校验更新。

## 本轮网页优化测量

基线是本日分享页优化已发布后的版本。Chrome 桌面 1440×900，下载 200 KiB/s、延迟 150 ms、CPU 降速 4 倍；关闭缓存，每页运行三次取中位数。静态资源使用 gzip level 6；API 使用相同固定数据，排除后端和邮箱内容变化。
